# Perfume Recommendation Platform

A full-stack perfume recommendation platform developed for discovering perfumes based on notes, accords, and user preferences.

## Features
- User authentication
- Perfume search and filtering
- Favorite perfumes
- Reviews and comments
- Personalized recommendations
- Similar perfume suggestions
- REST API integration

## Technologies Used

### Frontend
- React
- JavaScript
- HTML5
- CSS3
- Tailwind CSS
- Vite

### Backend
- PHP
- MySQL

## Tools
- Git
- GitHub
- VS Code
- XAMPP

## Project Goal
The goal of this project is to create a modern platform where users can discover perfumes more efficiently through detailed note-based filtering and recommendation systems.
